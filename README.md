# codm神人收集录

一个类维基的静态站点，用来收录 CODM 圈子里那些“神人”与事迹。
纯 HTML + CSS + 原生 JS，没有构建步骤，托管在 GitHub Pages。

**线上地址：<https://politeelm.github.io/codm/>**

---

## 一、结构

```
politeelm.github.io/
├── index.html                  跳到 /codm/
└── codm/
    ├── index.html              维基主页面（索引 / 条目 / 分类都在这一页渲染）
    ├── 404.html
    └── assets/
        ├── css/codm.css        样式
        ├── js/entries.js       ★ 所有条目数据 + 站点配置
        ├── js/codm.js          索引、搜索、分类、双链、反向链接
        └── images/             图片、图标（bg.jpg 背景、codm-* 图标）
```

地址规则（hash 路由）：

| 地址 | 内容 |
| --- | --- |
| `/codm/` | 索引：全部条目按首字分组 |
| `/codm/#/e/<slug>` | 某条条目 |
| `/codm/#/tag/<分类>` | 按分类筛选 |

## 二、一条条目长什么样

每个条目固定分**三块**：

| 板块 | 是否必填 | 说明 |
| --- | --- | --- |
| **神人事迹** | 必填 | 一两句话概括，显示在条目页顶部和索引列表里 |
| **简单回顾** | 可选 | 可以写多行，一行一段，适合按时间线列要点 |
| **长篇大论** | 可选 | 详细经过。没写就显示「暂时没有」 |

每条末尾自动带一行：`投稿：steamryy@outlook.com`（地址在 `entries.js` 的 `contact` 字段）。

## 三、新建条目

双击桌面「**codm管理端**」→ 点「＋ 新建条目」→ 选 txt。

txt 格式（前三行固定）：

```
甲某-开挂的神人              ← 第 1 行：条目名（必填）
自称从不作弊的那位。          ← 第 2 行：神人事迹（必填）
奇异人士,挂人天王             ← 第 3 行：分类

他先在直播间骂人。            ← 第 4 行起：简单回顾（可多行）
被人拆穿后删评控场。
最后改名跑路。

---                          ← 单独一行三个减号，是分界线

正文从这里开始。              ← 分界线以下：长篇大论（可省略）
```

> `---` 这行不能省。省了的话，第 4 行起全部会被当成「长篇大论」，简单回顾就是空的。

正文里还能用：

| 写法 | 效果 |
| --- | --- |
| `## 小标题` | 二级标题 |
| `> 一句话` | 引用块 |
| `- 一条` | 列表 |
| `[[另一个条目名]]` | 双链，自动跳到那条 |
| `![图注](图.png)` | 图片，自动复制进仓库 |

**文件名建议英文**（`jia.txt` → `#/e/jia`）；中文名会自动生成时间戳网址。

---

## 四、删除条目

同一个窗口：在列表里点选条目 → 点「－ 删除选中」→ 确认 → 自动删除并推送。

---

## 五、推送

改动之后点窗口里的「↑ 推送」，输入一句说明（留空用时间），它会自动加缓存版本号、提交、推送。

命令行等价：`.\发布.ps1 -消息 "说明"`

## 六、网站配置

`codm/assets/js/entries.js` 顶部的 `WIKI_CONFIG`：

```js
title:  "codm神人收集录",        // 站点标题
intro:  "收录 CODM 圈子里……",   // 首页那段介绍
catCounter: "https://count.getloli.com/@xxx?theme=cat-girls-yay",  // 猫娘计数
hitPath: "politeelm.github.io/codm",   // 普通计数用的路径
```

### 两种计数

| 位置 | 用什么 | 说明 |
| --- | --- | --- |
| 主页面 | **Moe-counter 猫娘**（`cat-girls-yay` 主题） | 图挂了会自动换成 hits.sh 徽章 |
| 条目页 | **hits.sh 普通徽章** | 每条独立计数，稳定可加载 |

Moe-counter 的公共实例（count.getloli.com）有时被人机验证挡住，
所以主页面做了自动降级，不会出现裂图。

## 七、几个说明

- **数据就一个文件**：`codm/assets/js/entries.js`，备份、迁移都只拷它。
- **没有数据库/后端**，所以没有编辑历史、没有登录。改条目：改 `entries.js` 再推送。
- **双链的坑**：`[[名字]]` 必须和某条目的 `title` 完全一致才会变链接，否则显示为灰色虚线的“未创建”。
- 条目多了索引会变长，目前没做分页（维基一般也不需要）。
