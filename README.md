# codm神人收集录

一个类维基的静态站点，用来收录 CODM 圈子里那些“神人”与事迹。
纯 HTML + CSS + 原生 JS，没有构建步骤，托管在 GitHub Pages。

**线上地址：<https://politeelm.github.io/codm/>**

---

## 一、结构

```
politeelm.github.io/
├── index.html                  跳到 /codm/
└── codm/
    ├── index.html              维基主页面（索引 / 条目 / 分类都在这一页渲染）
    ├── 404.html
    └── assets/
        ├── css/codm.css        样式
        ├── js/entries.js       ★ 所有条目数据 + 站点配置
        ├── js/codm.js          索引、搜索、分类、双链、反向链接
        └── images/             图片、图标
```

地址规则（hash 路由）：

| 地址 | 内容 |
| --- | --- |
| `/codm/` | 索引：全部条目按首字分组 |
| `/codm/#/e/<slug>` | 某条条目 |
| `/codm/#/tag/<分类>` | 按分类筛选 |

## 二、写一条新条目

### 用桌面快捷方式（推荐）

双击桌面「**新建条目**」→ 选一个 txt → 自动生成、推送。

txt 格式（前三行固定）：

```
甲某-开挂的神人              ← 第 1 行：条目名
一个自称从不作弊的人          ← 第 2 行：摘要（显示在索引里）
奇异人士,挂人天王             ← 第 3 行：分类，逗号隔开

正文从这里开始。              ← 第 4 行起：正文
```

正文里还能用：

| 写法 | 效果 |
| --- | --- |
| `## 小标题` | 二级标题 |
| `> 一句话` | 引用块 |
| `- 一条` | 列表 |
| `[[另一个条目名]]` | 双链，自动跳到那条 |
| `![图注](图.png)` | 图片，自动复制进仓库 |

**文件名建议英文**（`jia.txt` → `#/e/jia`）；中文名会自动生成时间戳网址。

### 手动改

打开 `codm/assets/js/entries.js`，往 `/* ENTRIES:START */` 下面加：

```js
{
  slug: "jia",                       // 网址里那段，别重复
  title: "甲某-开挂的神人",
  tags: ["奇异人士", "挂人天王"],
  date: "2026-11-05",
  summary: "一句话摘要",
  content: `
    <p>正文第一段。</p>
    <p>他和 [[乙某-控评大师]] 是一伙的。</p>
  `
},
```

> `content` 是模板字符串，里面**不要出现反引号**。

## 三、删条目

双击桌面「**删除条目**」→ 输入条目名（可以只输几个字）→ 确认 → 自动删除并推送。
名字匹配到多条时会让你选序号。

命令行：`.\工具\删除条目.ps1 -标题 "甲某"`

---

## 四、改完推送

双击桌面「**推送**」→ 输入一句说明（回车跳过）→ 自动加缓存版本号、提交、推送。

命令行：

```powershell
.\发布.ps1 -消息 "补了两条"
```

只改内容也用这个；它会把 `?v=` 的数字 +1，访客才不会看到旧缓存。

## 五、网站配置

`codm/assets/js/entries.js` 顶部的 `WIKI_CONFIG`：

```js
title:  "codm神人收集录",        // 站点标题
intro:  "收录 CODM 圈子里……",   // 首页那段介绍
catCounter: "https://count.getloli.com/@xxx?theme=cat-girls-yay",  // 猫娘计数
hitPath: "politeelm.github.io/codm",   // 普通计数用的路径
```

### 两种计数

| 位置 | 用什么 | 说明 |
| --- | --- | --- |
| 主页面 | **Moe-counter 猫娘**（`cat-girls-yay` 主题） | 图挂了会自动换成 hits.sh 徽章 |
| 条目页 | **hits.sh 普通徽章** | 每条独立计数，稳定可加载 |

Moe-counter 的公共实例（count.getloli.com）有时被人机验证挡住，
所以主页面做了自动降级，不会出现裂图。

## 六、几个说明

- **数据就一个文件**：`codm/assets/js/entries.js`，备份、迁移都只拷它。
- **没有数据库/后端**，所以没有编辑历史、没有登录。改条目：改 `entries.js` 再推送。
- **双链的坑**：`[[名字]]` 必须和某条目的 `title` 完全一致才会变链接，否则显示为灰色虚线的“未创建”。
- 条目多了索引会变长，目前没做分页（维基一般也不需要）。
